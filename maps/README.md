# Mapa świata (GLB)

Wrzuć tutaj swój plik mapy:

```
maps/Parking_map.glb
```

**Dokładna nazwa:** `Parking_map.glb` (scena `scenes/world/ParkingMap.tscn` ładuje ten plik).

Po skopiowaniu otwórz projekt w Godot — importer wygeneruje `parking_map.glb.import` automatycznie.

Inna nazwa pliku? Zmień ścieżkę w `scenes/world/ParkingMap.tscn` albo przemianuj plik.
